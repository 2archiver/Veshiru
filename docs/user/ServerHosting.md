# User Handbook - Server hosting

Veshiru is a Windows-exclusive emulator. It does not ship or support a dedicated server/room build, and Linux-based self-hosting (VPS, Docker images, Steam Deck hosts) is unsupported.

For playing together, use the in-game multiplayer features described in the [Multiplayer guide](./Multiplayer.md), such as direct connect or public lobbies.

If you previously self-hosted an Eden lobby on a Linux VPS: that path relied on a third-party Docker image and the Linux AppImage, neither of which Veshiru builds or tests. Existing rooms on your network created by other emulator forks remain reachable via direct connect as long as the protocol matches.
