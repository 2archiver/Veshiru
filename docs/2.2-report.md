## Not verified

- **Controllers.** Nothing was felt on any pad: not the PowerA wired Xbox One pad, not an Xbox,
  Pro Controller, Joy-Con or DualSense.
- **`renhdrum.dll`.** Never loaded, never called. Known about it: the release asset's SHA-256
  and size as GitHub reports them, and that its header declares the 18 functions Veshiru
  resolves. The release workflow checks the hash, the architecture and the export names.
- **The HD Rumble dialog.** Compiled by CI, never opened.
- **The sparse tile warning.** Not seen in a Mario Kart World log. No frame-rate effect is
  claimed in either direction.
- **PrepareAddOnContent.** No title that calls it was run, Donkey Kong Bananza included.
- **Games in general.** No game was booted on this release.
