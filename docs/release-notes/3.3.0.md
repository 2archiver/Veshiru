**3.3.0 adds two ways to play: a real Wii Remote over Bluetooth, and Joy-Con 2 mouse mode for the
host mouse. Controller mapping, the game library and rendering are otherwise unchanged.**

### Wii Remote

- **Bluetooth Wii Remote support (RVL-CNT-01 and RVL-CNT-01-TR).** Pair the remote in the
  operating system's Bluetooth settings first (hold **1** and **2** until the LEDs blink), then
  enable *Emulated Devices > Wii Remote (Bluetooth)* and restart Veshiru. The remote appears as
  `Wii Remote <n>` in the input device list, so it can be mapped like any other controller.
- Buttons, the accelerometer (published as motion) and the Nunchuk on the extension port are
  supported, including the Nunchuk stick on the left stick and C/Z on ZL/ZR. The remote's LEDs and
  rumble follow the emulated controller.
- **IR pointer.** With *Wii Remote IR pointer as right stick* enabled, the pointer is published as
  the right stick (and as motion) for games that use pointing. It needs a Sensor Bar, or two
  infrared LEDs, in front of the screen; without one the stick stays centred. The remote
  alternates between accelerometer + extension and accelerometer + IR + extension reports because
  Bluetooth packets cannot carry all three at once.
- Wii Remote `1` and `2` map to X and Y; the layout has no separate inputs for them.

### Joy-Con 2 mouse mode

- **The host mouse becomes a Joy-Con 2 mouse.** Enable *Joy-Con 2 Mouse > Enable Joy-Con 2 mouse
  mode*, then click in the render window to capture the mouse; **Ctrl+F9** gives it back. While
  captured the cursor is hidden and re-centred, and relative motion is sent as the Joy-Con 2
  mouse's `delta_x`/`delta_y`, with the virtual cursor kept inside the screen.
- Sensitivity is adjustable from 10% to 400%, vertical movement can be inverted, and the optional
  *Also move the right stick* projects the motion onto the right stick for games that only read
  stick input. Mouse buttons and the wheel keep working in both directions.
- No optical sensor is emulated: games see a normal Joy-Con 2 mouse report built from the host
  mouse.

### Good to know

- The Wii Remote driver is off by default, and mouse mode only captures the mouse after a click in
  the render window, so both features leave existing setups untouched.
- The Wii Remote driver is not a software Wii Remote: a keyboard or an emulated controller can be
  mapped to the emulated controller as before.
- Library icons are unchanged from 3.2: the Control NCA/NACP icon, the local cache and the HD
  artwork fallback all keep working the same way.
