**2.9.0 fixes the missing-UI bug on the VTX-HLE (NVN) path and makes the optimized settings the
defaults for everyone.**

### What's fixed

- **Missing UI on VTX-HLE (NVN).** Games that write their texture descriptor tables in bulk (the
  SDK's own `nvnTexturePoolWriteDescriptorTableData`, which Veshiru's HLE never sees) left those
  textures unregistered: every menu icon, panel and portrait that sampled them drew nothing.
  Mario Kart World's character select showed the 3D scene and a handful of elements with the rest
  of the interface invisible. Veshiru now reads the pool entry the game wrote and resolves the
  texture it names, registering it so later frames cost nothing. Gameplay and menus both keep
  their textures now.

### What's new

- **Optimized defaults for everyone.** Brand-new profiles, and **Emulation → Configure →
  Use recommended settings**, now write the tuning the 2.7/2.8 measurements on the reference
  i7-10750H + GTX 1650 machine produced: VTX-HLE (NVN) for Switch 2 titles, asynchronous shader
  and pipeline building, asynchronous presentation, bounded native async draws, GPU clocks held
  at their maximum, pipeline caches built while the game loads, and a one-time shader precache
  prompt. Existing installations keep whatever you chose; nothing is taken away.
- **Steadier gameplay pacing.** With asynchronous presentation and the pipeline library on by
  default, a slow frame no longer drags the next one with it, and pipeline links happen on
  workers while the game loads instead of in the middle of a race.

### Good to know

- The new defaults apply to new profiles and to the recommended-settings action; per-game
  overrides you already saved stay in place, and **Restore previous settings** still undoes a
  recommended-settings apply.
- `EDEN_NX2_NVN_HLE=1` / `=0` still forces the graphics path for one session if you want to
  compare VTX-HLE against the Emulated GPU.
- Mario Kart World keeps its 1.3-era care: HDR presentation, the lighting sparse-atlas handling
  and the legacy GPU timestamps ported from Eglantine (#870, #871) remain active on both paths,
  and the MKW 30 fps / dynamic-fps tweaks stay off in every optimized profile.
