**3.1.0 is a Switch 2 frame-rate, VRAM, and compatibility release: Mario Kart World moves onto
the low-VRAM two-thread GPU path with Mailbox pacing and dynamic FPS on by default, constant
buffer and buffer-cache stalls drop sharply on 4 GB GPUs, and Nintendo Switch Sports and Kirby
Air Riders get per-title compute fixes.**

### What's faster

- **Much higher FPS on 4 GB GPUs (GTX 1650 class).** Veshiru now defaults to the **Emulated**
  graphics path (`SPLIT=2` two-thread GPU with active 4 GB VRAM garbage collection and sparse
  ASTC mip trimming) instead of VTX-HLE, which previously exhausted 4 GB of VRAM during Mario
  Kart World races and spilled into PCIe memory (~30 FPS). Combined with **Mailbox** VSync,
  **Use Video Framerate**, and **Mario Kart World Dynamic FPS** enabled out of the box, frames
  no longer step down to a 30 Hz lock when a heavy scene briefly misses 16.67 ms, while 30 FPS
  menus and cutscenes still pace cleanly.
- **Smarter 64 KiB constant-buffer tracking.** Switch 2 games bind 64 KiB uniform banks
  thousands of times per frame. Veshiru now streams small uniform slices directly without
  touching the 64 KiB bank, tracks 4 KiB bank pages with fast SSE2 diffs and lock-free CPU write
  filters so unchanged frames upload zero bytes, and coalesces modified pages into a single GPU
  copy.
- **Dedicated presentation and video-decode service threads.** `nx2:gsv` presentation waits and
  FMV video decoding now run on their own service threads so cutscenes and swapchain pacing no
  longer stall game IPC.
- **Leaner buffer-cache memory and fewer redundant GPU copies.** Buffers of 128 MiB or larger no
  longer snowball into multi-hundred-MiB merged allocations across frames when a small neighbor
  touches one edge, joins of CPU-dirty buffers skip dead GPU-to-GPU copies, and GPU address
  range lookups cache contiguous page runs per thread.

### What's fixed

- **Mario Kart World dynamic FPS on the Emulated path.** The dynamic frame-time patch now
  applies on the default Emulated graphics path as well as VTX-HLE, keeping race speed steady
  across variable frame rates.
- **Nintendo Switch Sports (`04008E001F098000`).** Fixed compute storage buffer sizing (which
  previously truncated >8 MiB written buffers and left models black) and enabled legacy Ampere
  GPU timestamps so match logic advances normally.
- **Kirby Air Riders (`0400F9C0231B8000`).** Written native compute buffers larger than 8 MiB
  (such as the 64 MiB particle pool) now honor their descriptor size instead of clamping at
  8 MiB.

### Good to know

- Existing `qt-config.ini` files that want the new out-of-the-box pacing defaults can reset
  Graphics Path to **Emulated** and VSync Mode to **Mailbox** in Graphics settings (Recommended
  Settings leaves your chosen VSync mode untouched while applying the rest).
