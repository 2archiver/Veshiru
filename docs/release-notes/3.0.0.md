**3.0.0 is a performance and NVN graphics release: Mario Kart World's menus keep the textures
the game writes into its own descriptor tables, and the multi-second freeze when a game first
meets its compute shaders — Ocarina of Time's home menu — is gone.**

### What's fixed

- **Mario Kart World: the menus keep their textures.** 2.9 learned to resolve the textures the
  game writes into its descriptor tables itself, but the game keeps those tables in virtual
  memory pools, where 2.9 could not read them: the character select and the sticker menus still
  drew some panels and portraits as nothing. Veshiru now reads them where they actually live. If
  a texture is still missed, the log says which one and why (`pool table id …`), so it can be
  fixed instead of guessed at.

- **Ocarina of Time: no more freeze on the first home-menu frame.** The N64 app's home menu runs
  compute shaders that Veshiru used to translate and compile the moment each one first ran, one
  after the other on the thread that replays the frame — 16 seconds on the reference machine,
  every first visit after a cache clear. Those compiles now start on the background workers as
  soon as the frame's commands are queued, several at a time, so the freeze shrinks to a
  fraction of itself, and the disk cache keeps it from coming back on later runs.

### What's faster

- **Mario Kart World stutters less on first-seen menus and effects.** The pipeline lookahead
  that compiles upcoming graphics pipelines in the background now looks further ahead (512
  commands and 16 draws instead of 192 and 8), follows the game's texture and sampler pool
  changes, and is no longer stopped by copies, clears and sync commands between draws. In the
  2.9 log it caught 186 of 716 run-time compiles (every one it caught was used); the other 502
  were half-second stalls on the replay thread.
- **The same lookahead covers compute** for every title, not just the menus: new compute shaders
  are compiled before their first dispatch rather than during it.
- **The status log says where the time goes.** The `[nvn] replay …` heartbeat now shows each
  command's milliseconds per present, so a slow session's log reads without hand arithmetic.

### Good to know

- Both fixes are covered by unit tests; the hardware numbers come from the reference machine
  (i7-10750H, GTX 1650 4 GB) with the same settings as the 2.9 logs. If a session is still slow,
  send the log: the new `pool table` and `compute lookahead` lines say what happened.
- `EDEN_NX2_NVN_MKW_DRIVER_CACHE=1` keeps the NVIDIA driver pipeline cache for Mario Kart World
  for one session (it is normally started empty for that game); an A/B switch for testing,
  nothing you need to set.
- Smart BC stand-ins stay off by default, as in 2.9; nothing about the defaults changes.
