**2.8.0 introduces VTX-HLE (NVN)**, an optional high-level graphics path for Switch 2 games,
alongside Veshiru's existing Emulated GPU renderer.

### What's new

- **Optional VTX-HLE graphics path for Switch 2 games.** Switch between **Emulated GPU** (still
  the default) and **VTX-HLE (NVN)** in **Configure → Graphics → Graphics path** or per game in
  game properties. Instead of running the game's own NVN2 driver to emit hardware GPU commands,
  VTX-HLE answers NVN2 calls directly and replays recorded command lists on Vulkan.
- **VTX-HLE options and smart BC texture stand-ins.** When **VTX-HLE (NVN)** is selected, controls
  that only apply to Emulated GPU are greyed out with explanations (your saved settings stay
  intact), and VTX-HLE options appear for in-pass occlusion queries, fast-linked pipelines, fewer
  inter-pass syncs, smart BC ASTC stand-ins, and 60-second shader refresh testing.
- **Clean shader cache switching.** Switching a Switch 2 game from Emulated GPU to VTX-HLE clears
  incompatible shader caches once automatically; **Remove Vulkan Pipeline Cache** clears both
  Emulated GPU and VTX-HLE pipeline caches.

### Good to know

- VTX-HLE is opt-in (**Emulated GPU** remains the default) and requires Vulkan with buffer device
  addresses and 64-bit shader integers; Switch 1 titles and unsupported Vulkan devices fall back to
  Emulated GPU automatically (`EDEN_NX2_NVN_HLE=1` or `=0` overrides the path for one session).
- Frame generation, HDR output, and advanced presentation filters past bilinear are not active on
  VTX-HLE frames yet; their controls are greyed out while VTX-HLE is chosen.
- Build and test verification is tracked via the Windows `clang-cl` CI workflow; per-game visual
  and performance behavior on VTX-HLE depends on each title and GPU driver.
